```go
func JWTMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 1. 从请求头获取 Token
        token := c.GetHeader("Authorization")  // Line 35
        
        // 2. 解析和验证 Token
        claims, err := ParseToken(token)  // Line 42
        
        // 3. 将用户地址存入上下文
        c.Set("user_address", claims.UserAddress)  // Line 49
        
        // 4. 继续处理请求
        c.Next()  // Line 50
    }
}
```
验证逻辑：
检查 Authorization header 是否存在
调用 ParseToken() 解析 JWT
验证签名算法（防止算法混淆攻击）
验证签名有效性
验证过期时间
提取 user_address 并存入 Gin Context
如果验证失败：
返回 HTTP 401 Unauthorized
中断请求处理（c.Abort()）

```go
func EstimateGas(to string, data []byte) (uint64, error) {
    toAddr := common.HexToAddress(to)
    msg := ethereum.CallMsg{
        To:   &toAddr,
        Data: data,
    }
    
    // 调用 RPC 节点的 eth_estimateGas
    gas, err := Client.EstimateGas(Ctx, msg)  // Line 177
    if err != nil {
        logger.Logger.Warn("Gas估算失败，使用默认值", zap.Error(err))
        return 300000, nil  // 降级处理
    }
    return gas, nil
}
```
Gas 估算流程：
构造一个模拟交易（不会真正执行）
调用以太坊节点的 eth_estimateGas RPC 方法
节点模拟执行交易并返回所需 Gas
如果估算失败，使用保守默认值 300,000

```go
// Line 93-105: 每3秒检查一次待确认交易
func (t *TransactionTracker) pollLoop() {
    ticker := time.NewTicker(t.pollInterval)  // 3秒
    defer ticker.Stop()
    
    for {
        select {
        case <-t.ctx.Done():
            return
        case <-ticker.C:
            t.checkPendingTxs()  // 检查所有 pending 交易
        }
    }
}
```
工作流程：
维护一个内存中的交易哈希映射表
每3秒轮询一次所有 pending 状态的交易
调用 eth_getTransactionReceipt 查询交易状态
更新交易状态（pending → confirmed/failed）
记录区块号和确认数
